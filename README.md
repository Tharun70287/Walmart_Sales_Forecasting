# Walmart Sales Forecasting Project

## 📌 Overview
This project analyzes Walmart weekly sales data across multiple stores.  
It includes:
- Exploratory Data Analysis (EDA)
- Outlier detection
- Seasonal trend analysis
- Store performance ranking
- Forecasting next 12 weeks using SARIMAX

## 📂 Files
- `Walmart_Sales_Forecasting.ipynb` → Colab notebook with full code
- `walmart.csv` → Dataset (if allowed to share)
- `README.md` → Project documentation

## 🚀 How to Run
1. Open the notebook in Google Colab.
2. Upload the dataset (`walmart.csv` inside a zip).
3. Run cells step by step.

## 📊 Results
- Seasonal sales trends identified
- Top and worst performing stores
- Forecasts for next 12 weeks
